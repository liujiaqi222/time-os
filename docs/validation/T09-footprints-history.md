## 统计契约

- 首页、足迹、目标投入汇总及 MCP 使用共同统计入口与同一 focus SQL。读取显式返回 now、timezone、weekStartsOn、期间边界和秒单位；日历详情沿用页面的设置/时间快照。
- observed 按真实 focus 区间裁剪到期间、now 和 deadline；休息、暂停、到时等待、cancelled 不计入。只改文字不切换时间依据。
- manual/corrected 按声明墙钟范围比例分配有效时长，以累计分配差值保证整数秒守恒。更正保留原始 observed intervals，统计使用更正结果，避免双算。
- 期间次数按有正投入的 Session 去重；每日次数独立去重，跨日执行可在两日各出现一次。Task 按当前 completed 状态和 completedAt 单独计数；reopen 后不计完成，取消 Session 不撤销 Task 完成。
- `stats_get` 支持 all/custom/daily/byGoal，daily 最多 366 个本地日期。all 返回汇总而非全部记录。
- `sessions_list` 默认按 startedAt；`dateMode=focus` 要求有界 from/to，按有效投入交集筛选。列表每页最多 100 条，游标包含原排序时间与 id，边界记录纠错或 Task reopen 后仍可翻页。
- 新增索引迁移 `drizzle/0003_past_black_tarantula.sql`。仅应用于本地测试库/隔离 schema，业务数据库尚未迁移。
